XMLHttp REQUEST(ues before fetch)

The five states are: 0 (UNSENT): The XMLHttpRequest client has been created, but the open() method has not been called yet. 1 (OPENED): The open() method has been invoked, and the request is set up, but the send() method has not been called. Request headers can be set during this state. 2 (HEADERS_RECEIVED): The send() method has been called, and the server has responded with headers and status (e.g., 200 for "OK" or 404 for "Not Found"). 3 (LOADING): The response body is being received. The responseText property holds partial data while the request is in process. 4 (DONE): The fetch operation is complete, and the full response has been received and is ready for use. The data transfer is finished, whether successfully or in failure.
